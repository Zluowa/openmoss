# Moss zh-CN 产品术语表

此术语表约束 Moss 自有、面向用户的简体中文文案。它是语义映射，不是对运行时内容做全局替换。

## 核心术语

| 英文概念                     | zh-CN  | 使用规则                                                                                                                           |
| ---------------------------- | ------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| chat / conversation / thread | 对话   | 三者在产品界面中都指一段可继续的消息历史；新建、导入、归档、排序和打开操作统一使用“对话”。代码、协议和 API 标识仍可保留 `thread`。 |
| project                      | 项目   | Moss 中登记的仓库或文件夹及其对话集合。                                                                                            |
| workspace                    | 工作区 | 对话运行时使用的工作目录语境；不要与“项目”互换。                                                                                   |
| worktree                     | 工作树 | Git 工作树或 Moss 创建的隔离工作目录。需要指出实现时可写“Git 工作树”。                                                             |
| provider                     | 服务商 | 提供模型运行能力的集成；动态服务商名称本身不翻译。                                                                                 |
| account                      | 账号   | 用户连接到服务商的凭据身份。界面用“账号”，不用“账户”。                                                                             |
| model                        | 模型   | 模型类型或具体选择；动态模型名称与 slug 值不翻译，产品标签可写作“模型标识”。                                                       |
| Agent                        | 智能体 | 执行任务的智能体角色。品牌或产品专名（例如 Cursor Agent）保持原名。                                                                |

## 权限模式

| 稳定值              | 英文             | zh-CN    | 含义                                         |
| ------------------- | ---------------- | -------- | -------------------------------------------- |
| `approval-required` | Ask for approval | 需要批准 | 编辑外部文件或使用互联网时始终请求用户批准。 |
| `auto`              | Approve for me   | 自动批准 | 仅在检测到操作可能不安全时询问用户。         |
| `full-access`       | Full access      | 完全访问 | 不受限制地访问互联网和电脑上的文件。         |

## 对话范围的歧义消解

- 一般对象和已知上下文中的对象统称“对话”，不重新引入“线程”。
- 当同一界面同时提供脱离项目的 chat 与项目内 thread，或入口离开上下文后会产生歧义时，分别使用“全局对话”和“项目对话”。
- 全局入口写作“新建全局对话”或“打开新建全局对话主页”；项目入口写作“新建项目对话”，并在辅助功能名称中保留动态项目名，例如“在 {项目名} 中新建项目对话”。
- 一旦进入具体对话，后续的打开、归档、恢复和删除操作继续简称“对话”，避免重复范围信息。

## 保留项与边界

- 不翻译专有名称、服务商名称、模型名称、用户名称、项目名称、仓库内容、文件路径、命令、错误详情、事件标识和 model slug 值。
- `Git` 与 `MCP` 是有意保留的技术术语；`Git worktree` 在产品中文里写作“Git 工作树”。
- `Codex`、`Claude`、`ChatGPT`、`Moss` 等品牌名保持原样。
- 不对用户或服务商产生的消息正文应用本表；仅本地化 Moss 自有的可见文案、工具提示和辅助功能名称。
- 英文 locale 保持现有英文产品文案，不因中文术语统一而改写。

## 执行方式

新增产品文案应通过 `apps/web/src/localization.tsx` 的 typed translation key 提供 en/zh-CN 两套值，并在组件的可见文本、`aria-label`、标题和说明中使用同一语义 key。动态专名通过格式化参数插入，不能进入静态翻译表。
