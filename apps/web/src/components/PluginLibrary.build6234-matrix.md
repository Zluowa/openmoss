# Build6234 Plugin / Skill UI clean-room matrix

Scope: Moss web surfaces owned by `PluginLibrary*`, `PluginManagementPanel*`,
`SkillsSettingsPanel*`, related web lib, tests, and CSS. The matrix records the
observable product contract; it does not copy proprietary source or artwork.

Evidence boundary: #118 is the UI implementation PR only. The independent #121
frozen-reference line (`ceba6777b2065edc9a400b2bd561c5d734d4fab2`) records signed
Codex Desktop `26.730.61639`, build `6234`, CLI/app-server `0.147.0-alpha.1.2`,
canonical browse route `/skills`, Settings Manage URL
`/settings/plugins-settings`, Manage tabs `Plugins` / `Apps` / `MCP`, and the
required 56-cell visual matrix. That reference is read-only and is not absorbed
by #118; this PR does not copy proprietary code, screenshots, or artwork.
Only a final integration SHA that intentionally contains both independently
reviewed lines may regenerate acceptance-bound manifests, receipts, or captures.

MCP dependency boundary: the central d2d3 #116 contract defines the stable
`resourceKind` values `skill` / `plugin` / `mcp` and the typed inventory/plan/apply/
rollback seam. The current #118 UI head does not contain those backend contracts;
this PR therefore adds only a web-typed MCP preview placeholder and keeps
production apply fail-closed. Final integration must connect the existing #116
RPC/receipt adapter; #118 does not copy or recreate that server schema.
The web preflight normalizes and rejects unsafe MCP names/selectors, while the
server remains authoritative and revalidates them before issuing a receipt.
Import scan/read/write/rollback failures use typed localized fallbacks; unknown
native details are diagnostic-only and are never rendered in the dialog.
